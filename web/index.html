Assignment logic

The rules are explicit.

01

Validate input

Warehouses and agents can be lists or dictionaries. Coordinates must be two finite numbers and IDs must be unique.

02

Assign first

Every package is assigned before movement begins, using each agent's original position and Euclidean distance to the package warehouse.

03

Simulate movement

An assigned agent travels from its current position to the warehouse, then to the package destination. The next trip starts from that destination.

04

Rank fairly

Lower average distance wins. Exact ties prefer more delivered packages, then alphabetical agent ID.

The browser demo mirrors the documented assignment rules. The original Python implementation and its test suite remain in the repository as the reference implementation.
